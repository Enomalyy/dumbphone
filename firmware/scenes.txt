# scenes.txt — the golden-frame recipes, one line per scene (spec §16.1).
#
# Format:  <frame> <kind> <flags...>
#   frame  = the PNG file name in ../screenshots/ (no directory, no .png)
#   kind   = panel  -> rendered with --shot    (the panel, device pixels)
#            window -> rendered with --shot-win (bezel + panel compose)
#   flags  = passed verbatim to build-host/dumbphone-desktop; the vocabulary
#            is the binary's own CLI (see host/src/main.c): --screen,
#            --cycle left|right N, --key <name> [N], --activate N,
#            --swipe up|down|left|right [dist], --tap x y, --press <id>,
#            --hold <ms>, --menu-style carousel|grid|moving, --theme dark|light,
#            --font header|text|subtext[:N], --geom WxH, --scale N.
#
# Shot mode freezes the clock at 20:36, so every scene is reproducible at
# any time. `just golden-check` renders each scene and compares it with the
# committed PNG; `just golden-update` rewrites the frames (the only way they
# change). A line here is a promise: the frame exists and is made exactly
# this way.
#
# EXCLUDED: browser-viewport.png — a live capture of just run-desktop's web
# viewport (frame_server JPEG stream at 18 fps); it shows a running app, not
# a frozen state, so it has no recipe and is not checked.
